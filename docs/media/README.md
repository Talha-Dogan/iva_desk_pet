# Görseller

Bu klasöre README'de görünecek fotoğraf ve gif'leri koy. README içinde nereye ne
geleceği `<!-- GORSEL: ... -->` yorumlarıyla işaretli; dosyanı koyduktan sonra ilgili
yorum satırını açman (yorumu kaldırman) yeterli.

## Önerilen çekimler

| Dosya adı | Ne çek |
|---|---|
| `iva-hero.gif` | En üstteki ana görsel — İva masada, yüz ekranı açık, göz kırpıyor |
| `happy.gif` | Mutlu yüz (gözler ^ ^) |
| `sad.gif` | Üzgün yüz |
| `talk.gif` | Konuşurken ağız hareketi |
| `sleep.gif` | Uyku modu ("z z z" ve kapalı gözler) |
| `donanim.jpg` | Breadboard'un yakın fotoğrafı |
| `baglanti-semasi.jpg` | (istege bağlı) kendi çizdiğin kablolama şeması |

## İpuçları

- **Gif için:** telefonla video çek, sonra ücretsiz bir "video → gif" aracıyla dönüştür
  (ör. ezgif.com). 3-5 saniye, 480px genişlik yeterli.
- **Boyut:** gif'leri 5 MB altında tut; repo şişmesin.
- **Ekran çekimi net olsun:** OLED küçük olduğu için yakından, karanlık ortamda çek —
  yanan pikseller daha net görünür.
